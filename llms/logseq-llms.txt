# Logseq

> Logseq is a privacy-first, open-source platform for knowledge management and collaboration. It is a local-first outliner that stores notes as plain Markdown and Org-mode files linked into a personal knowledge graph. Its developer surface is a JavaScript/TypeScript plugin SDK (@logseq/libs) plus an in-app HTTP APIs server exposing Editor and App proxy methods to local automation. There is no hosted public REST API. Developed in Clojure/ClojureScript, licensed AGPL-3.0, and backed by a16z.
